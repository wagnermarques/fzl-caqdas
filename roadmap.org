* 🧭 Visão Geral do Projeto (Project Overview)

O **Qualitative Research Assistant (CAQDAS)** é uma aplicação voltada para apoio completo ao ciclo de pesquisa qualitativa e métodos mistos.
Projetado como um PWA de alta performance e acessibilidade, utiliza Web Components nativos com a suíte *FZL UI* (~fzl-fund-ui~: ~fzl-fund-appshell--lit~, ~@fzl/webcomponents-lit~ e ~@fzl/design-tokens~).

** Objetivos Principais
- Coletar, organizar, transcrever, codificar, interpretar e visualizar dados não-numéricos (entrevistas, documentos, áudios, vídeos e imagens).
- Garantir total autonomia ao pesquisador no processo interpretativo, complementado por ferramentas de assistência analítica e IA.
- Facilitar exportação direta e integração com Python / Pandas para análise de frequências, coocorrências e métodos mistos.

** Pilha Tecnológica (Tech Stack)
- *Shell & Roteamento*: ~fzl-fund-appshell--lit~ (Drawer, Header, A11y, Temas Claro/Escuro/Alto Contraste, PWA Workbox).
- *Componentes Web*: Lit 3.x, ~@fzl/webcomponents-lit~ (~<fzl-lit-card-list>~, ~<fzl-lit-reader-content>~, ~<fzl-lit-reader-mark-bar>~, ~<fzl-lit-data-grid>~), ~@material/web~ (Material 3).
- *Tokens de Design*: ~@fzl/design-tokens~ (variáveis CSS para cores semânticas, tipografia e elevações).
- *Armazenamento*: IndexedDB via Dexie/idb com persistência reativa e exportação JSON/SQLite compatível com QualCoder/Taguette.
- *Processamento Textual & Mídia*: Web Audio API, Web Workers para indexação e tokenização de texto, leitor de áudio com timeline de transcrição sincronizada.
